a CasaOs Remake made in python in italy

## INFO

The default account is **admin** and the password is **admin123** 

## INSTALL PROCEDURE

1. in your linux terminal type **git clone https://github.com/ChrisWorldssYT/xOs-**
2. type **cd xOs-**
3. type **chmod +x ./setup.sh**
4. run **./setup.sh** as an administrator **(With Sudo)**
5. Wait till it is finished
6. Enjoy
